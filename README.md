# Flujo comun de git

1. Traer los cambios
```bash
   git fetch
   git pull origin main
   ```
2. Estado actual del repositorio local
```bash
   git status
```   

3. Agregar cambios a capa staging
```bash   
git add
```

4. Generar mi primer commit
```bash
git commit -m "Mi primar commit in github"
```

5. Empujar los cambios
```bash
git push origin main
